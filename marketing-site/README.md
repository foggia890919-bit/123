# 회사 홈페이지 + 자체 관리자(CMS)

`suwan-medical.co.kr` 류의 **제약 CSO 회사 소개 사이트**를 본떠 만든 **독립형** 홈페이지입니다.
기존 BIZ 플랫폼과 완전히 분리돼 있으며, **외부 라이브러리 없이 Node.js 내장 모듈만**으로 동작합니다.

## 무엇을 할 수 있나

- 공개 홈페이지(`/`)를 방문자에게 보여줍니다.
- 관리자 페이지(`/admin`)에서 **직접** 내용을 수정합니다.
  - 섹션 **추가 / 삭제 / 순서변경(▲▼) / 숨김(👁)**
  - 각 섹션의 **문구·연락처·색상·로고** 수정
  - **이미지 업로드**(드래그한 파일 → 자동 저장) 또는 URL 입력
  - 오른쪽 **실시간 미리보기**로 즉시 확인 → 상단 **저장**으로 반영

## 실행 방법

```bash
cd marketing-site

# 비밀번호와 포트를 지정해서 실행 (지정 안 하면 기본값 사용)
ADMIN_PASSWORD=원하는비밀번호 PORT=3000 node server.js
```

- 사이트:   http://localhost:3000/
- 관리자:   http://localhost:3000/admin  (위에서 정한 비밀번호로 로그인)

> 비밀번호를 지정하지 않으면 기본값 `admin1234` 로 동작합니다. 실제 운영 시 반드시 `ADMIN_PASSWORD` 를 설정하세요.

## 구조

| 경로 | 역할 |
|------|------|
| `server.js` | 라우팅·인증·저장·이미지 업로드·홈페이지 SSR (의존성 0) |
| `render.js` | 콘텐츠(JSON) → HTML 렌더러. 서버와 관리자 미리보기가 공용 |
| `content/site.json` | **모든 내용이 저장되는 단일 파일** (관리자에서 저장 시 갱신) |
| `public/styles.css` | 공개 홈페이지 디자인 |
| `public/admin.html` | 관리자 화면(편집 UI) |
| `data/uploads/` | 업로드한 이미지 저장 위치 |

## 섹션 종류

히어로, 숫자 통계, 회사 소개, 강점 카드, 단계/로드맵, 연혁, 이미지 갤러리,
자유 텍스트, 행동유도 배너(CTA), 문의/오시는 길 — 관리자에서 자유롭게 조합.

## 배포 메모

- **로컬/일반 Node 서버(예: 직접 띄운 VM, Render, Railway, Fly.io)** 에서는 그대로 동작하며, 관리자에서 수정한 내용이 `content/site.json` 과 `data/uploads/` 에 **파일로 저장**됩니다.
- **Vercel/Netlify 같은 서버리스**에 올리면 파일 쓰기가 유지되지 않습니다. 이 경우 저장소를 DB/오브젝트 스토리지로 바꿔야 하며, 필요하면 알려주세요(연결해 드립니다).

## Canva 연동에 대해

- 이 사이트의 "직접 수정" 핵심은 위 **자체 관리자**입니다.
- Canva는 **배너/그래픽 이미지를 디자인**하는 보조 도구로 활용합니다.
  - Canva에서 만든 이미지를 내려받아 관리자 이미지 업로드로 넣으면 됩니다.
  - (선택) Canva MCP를 연결하면 제작 단계에서 이미지를 자동 생성해 넣을 수도 있습니다.
