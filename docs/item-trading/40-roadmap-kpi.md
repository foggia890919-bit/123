- [ ] 인증(이메일/소셜) + 휴대폰 본인인증(PASS/NICE)

- [ ] 분쟁 신청/티켓/관리자 처리

### 2.3 운영
- [ ] 분쟁 대시보드(SLA 카운트다운)
- [ ] 사용자 검색/제재

### 2.4 비기능
- [ ] CI/CD, 스테이징 환경

## 3. KPI / 성공 지표

### 3.1 North Star
- **"안전거래로 종결된 거래 건수 (Weekly Settled Orders)"**

### 3.2 보조 지표

| 카테고리 | 지표 | 목표(MVP 종료시점 가설) |
|---|---|---|
| 트래픽 | 주간 활성 사용자 WAU | 5,000+ |
| 전환 | 방문→가입 | 8% |
| 등록 | 신규 상품/주 | 1,000+ |
| 거래 | GMV/주 | 5천만 원 |
| 거래 | 평균 객단가 | 5만 원 |
| 거래 안정성 | 분쟁율 | < 1.5% |
| 거래 안정성 | 환불율 | < 0.8% |
| 거래 안정성 | 평균 분쟁 처리 시간 | < 48h |
| 만족 | 거래 평점 평균 | ≥ 4.5/5 |
| 비즈니스 | 수수료 수익/주 | 300만 원 |

### 3.3 가드레일

- 분쟁율이 2주 연속 3% 초과 → 신규 카테고리 출시 동결.
- 환불율이 임계 초과 → 신규 가입 한도 자동 강화.
- PG 정산 지연 발생 시 출금 한도 자동 하향 + 공지.

## 5. 단계별 출시 게이트

각 페이즈 종료 전 통과해야 다음으로 넘어간다.

- **P1 → P2**: 결제/정산 회계 검증 통과, 분쟁 SLA 7일 평균 달성, 보안 자체 점검 Pass.
- **P2 → P3**: WAU ≥ 3,000, 분쟁율 < 2%, 5종 게임 어드민 안정.
- **P3 → P4**: 월 GMV ≥ 2억, 광고 매출 발생, 운영 자동화 50% 이상.
