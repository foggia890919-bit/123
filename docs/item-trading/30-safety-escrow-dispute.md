# 안전거래·에스크로·분쟁 처리 정책

---

## 1. 안전거래(에스크로) 원칙

1. 구매자가 결제한 금액은 **회사가 보관**한다(에스크로 계좌 분리).
2. 구매자가 게임 내 수령을 확인(또는 자동 확정 조건 충족)해야 판매자에게 정산된다.
3. 분쟁이 발생하면 정산은 즉시 **동결**되고 운영자가 중재한다.
4. 모든 머니 이동은 `LedgerEntry`에 append-only로 남는다.

> 법적 형태 검토 필요: 통신판매중개업 + 결제대행 약정. 자체 에스크로 운영 시 전자금융거래법 검토 필수(`50-legal-checklist.md`).

---

## 2. 거래 단계별 정책

| 단계 | 책임 | 만료/타임아웃 | 자동 동작 |
|---|---|---|---|
| 결제 대기 | 구매자 | 30분 | 미결제 시 주문 자동 취소 |
| 인계 대기 | 판매자 | 24시간 | 미인계 시 분쟁 자동 생성 옵션 |
| 인계 완료 → 수령 확인 | 구매자 | 48시간 | 자동 확정 → 정산 큐 진입 |
| 정산 보류 | 시스템 | T+1 영업일 | 검증 후 wallet.available 증가 |
| 출금 | 사용자 | 신청 후 1영업일 | 송금 실행, 실패 시 재큐잉 |

## 3. 거래 한도 정책 (사기 방지)

| 등급 | 조건 | 일 결제 한도 | 월 결제 한도 | 일 인출 한도 |
|---|---|---|---|---|
| Lv0 | 가입 직후 | 5만 원 | 30만 원 | 0 |
| Lv1 | 휴대폰 본인인증 | 30만 원 | 200만 원 | 30만 원 |
| Lv2 | + 정산계좌 1원 인증 | 100만 원 | 500만 원 | 100만 원 |
| Lv3 | + 거래실적/평점 N점 이상 | 300만 원 | 1,500만 원 | 300만 원 |
| Lv4 | 사업자등록(전문 셀러) | 별도 협의 | 별도 협의 | 별도 협의 |

> 한도 초과 시 KYC 단계 안내 모달 노출.

## 4. 채팅 마스킹 / 외부거래 유도 차단

- 정규식 + ML 분류기로 자동 마스킹: 전화번호, 카카오ID, 디스코드ID, 계좌번호, URL.
- 마스킹된 메시지는 `redacted=true`로 저장(분쟁 시 운영자만 원문 열람).
- "외부거래 유도" 신고 누적 시 자동 거래 정지 + 운영자 큐.

## 5. 분쟁 처리 절차

### 5.1 SLA
- 1차 응답: **24시간 이내**
- 단순 분쟁(증빙 명확): **3영업일 이내** 결론
- 복잡 분쟁: **7영업일 이내** 결론

### 5.2 처리 단계

1. **접수**: 양 당사자 진술 자동 수집(채팅 로그·결제 정보 자동 첨부).
2. **증빙 요청**: 게임 우편/거래 스샷, 게임사 로그(가능 시).
3. **검토**: 운영자가 채팅 원문 + 증빙 비교.
4. **결정**: REFUND / RELEASE / PARTIAL.
5. **집행**: 환불/정산 + 어뷰저 제재 검토.
6. **이의제기**: 결정 후 7일 이내 1회 가능, 다른 운영자가 재검토.

### 5.3 결정 가이드라인

| 시나리오 | 기본 결정 |
|---|---|
| 판매자가 인계하지 않음 (DELIVERED 표시 X, 증빙 없음) | 전액 환불 |
| 인계는 됐으나 옵션/수량 불일치 명확 | 부분 환불 또는 전액 환불 + 셀러 페널티 |
| 구매자가 수령 후 허위 신고(증빙 충돌, 게임사 기록 일치) | 정산 실행 + 구매자 페널티 |
| 양측 증빙 불충분 | 거래액 50/50 또는 최후 진술 후 결정 |
| 외부거래 유도 사기 (회사 외부 송금) | **회사 책임 없음** 안내 + 형사 신고 가이드 |

### 5.4 운영자 권한

- 거래 상태 강제 전이(주의해서 사용, 항상 `AdminAuditLog` 기록).
- 사용자 정지(임시/영구), 거래 한도 강제 하향.
- 환불 발행(원장 보정).

## 6. 사용자 제재(Sanction) 매트릭스

| 유형 | 1차 | 2차 | 3차 |
|---|---|---|---|
| 외부거래 유도 | 7일 정지 | 30일 정지 | 영구 정지 |
| 허위 인계 | 30일 정지 | 영구 정지 | — |
| 자전거래/시세조작 | 영구 정지 | — | — |
| 중복 계정 | 30일 정지 | 영구 정지 | — |
| 욕설/협박 | 경고 | 7일 정지 | 30일 정지 |

제재 시 사유·근거 채팅·운영자ID를 `AdminAuditLog`에 남긴다.

---

## 7. 환불/정산 회계 처리

- 환불: 결제수단 원복(카드 취소/계좌 환급). 7일 경과 시 가상계좌로 환급.
- 정산: T+1 영업일 자동 정산 (오전 10시 배치).
- 수수료 회수: 정산 시 차감, 환불 시 자동 면제(또는 비율 면제).

---

## 8. 모니터링/리포팅

- **실시간 대시보드**: 분쟁율(7일/30일), 환불율, 평균 SLA, 신고 건수.
- **알람**:
  - 분쟁율이 평균의 2σ 초과 시 슬랙 경보.
  - 한 사용자 24h 내 분쟁 ≥ 3건 시 자동 거래 정지.
  - 결제 실패율 임계 초과 시 PG 우회 라우팅.
