## 1. 정보 구조 (IA)

```
[비로그인 홈]
 ├─ 게임 선택
 │   └─ 카테고리(머니/아이템/계정/캐릭터/기프트)
 │       └─ 상품 리스트(검색·필터·정렬)
 │           └─ 상품 상세
 ├─ 검색
 ├─ 시세
 ├─ 고객센터(공지/FAQ/신고)
 └─ 로그인 / 회원가입

[로그인 홈]
 ├─ 마이페이지
 │   ├─ 판매: 등록 상품 / 진행 거래 / 정산 내역 / 평가
 │   ├─ 구매: 찜 / 진행 거래 / 구매 내역 / 평가
 │   ├─ 알림 / 워치리스트
 │   ├─ 계좌·정산 정보
 │   └─ 본인인증·보안 설정
 ├─ 상품 등록 (단건/일괄)
 ├─ 채팅(거래 채팅 / 1:1 문의)
 └─ 분쟁 신청 / 진행 상태

[관리자]
 ├─ 회원 / KYC 검토 / 제재
 ├─ 상품 / 카테고리 / 게임 마스터
 ├─ 거래 / 결제 / 정산
 ├─ 분쟁 / CS 티켓
 ├─ 광고 / 쿠폰
 └─ 통계 대시보드
```

## 3. 핵심 사용자 플로우

### 3.1 판매자 — 상품 등록 → 판매 → 정산

```
[로그인]
  → 본인인증/계좌 등록 (최초 1회)
  → 상품 등록
      · 게임 선택 → 카테고리 선택
      · 동적 폼(서버 단가/수량 등) 입력
      · 가격 / 즉시판매가 / 협상가능 토글
      · 사진/영상(선택) 업로드
      · 거래 가이드 동의 (게임별 정책)
  → 등록 완료 (검수 자동 통과/보류)
  ↘ 구매자 채팅/요청 알림
      · 채팅에서 거래 합의
      · "거래방" 생성 → 거래 코드 발급
  → 결제 완료 알림 받음 (금액 에스크로 보관)
  → 게임 내 전달(아이템 우편/계정 인계)
  → 구매자 수령 확인 또는 자동 확인(48h)
  → 정산 가능 잔액 → 출금 신청 → 익일 입금
```

### 3.2 구매자 — 검색 → 결제 → 수령

```
[비로그인]
  → 검색/필터로 상품 발견
  → 상품 상세 → "구매 요청" 버튼
[로그인 필요 게이트]
  → 채팅으로 합의(서버/캐릭명 등 전달)
  → 결제 (에스크로 보관)
  → 판매자 인계 알림
  → 게임 내 수령
  → "수령 확인" 클릭 → 거래 종료 → 평점 작성
```

### 3.3 분쟁 발생

```
구매자/판매자가 "분쟁 신청"
  → 거래 자동 동결 (정산 보류)
  → 운영자 티켓 자동 발급 (24h SLA)
  → 양 당사자에게 증빙 요청
      · 채팅 로그 / 게임 우편 스샷 / 거래 시간
  → 운영자 결정
      · 환불 / 정산 / 부분 환불 / 추가 증빙
  → 결과 통보, 환불·정산 처리, 어뷰저 제재 검토
```

### 3.4 회원가입 / KYC

```
이메일 가입
  → 이메일 인증
  → 휴대폰 본인인증 (PASS)
  → (판매자 전환 시) 정산 계좌 등록 + 1원 인증
  → 거래 한도 차등(미인증 < 본인인증 < 계좌인증)
```

## 4. 화면별 상세 와이어 가이드

> 도구는 Figma 권장. 본 문서는 핵심 컴포넌트 텍스트 명세만.

### 4.1 홈
- 상단: 게임 셀렉터(아이콘 그리드), 검색바.
- 인기 카테고리 / 실시간 거래 / 신규 등록 캐러셀.
- 시세 위젯(주요 게임 골드 시세).
- 안전거래 안내 배너 (전환 후킹).

### 4.2 상품 리스트
- 좌: 필터 사이드(서버, 가격대, 옵션, 거래 방법).
- 본문: 카드 리스트(이미지·제목·가격·판매자평점·태그).
- 정렬: 최신/낮은가격/높은평점/거래활발.
- 무한 스크롤 + URL 쿼리스트링 보존.

### 4.3 상품 상세
- 좌: 이미지 갤러리, 옵션 표.
- 우: 가격, "구매하기"·"채팅하기" CTA, 판매자 카드(평점/거래수/응답시간).
- 하단: 거래 정책, 안전거래 안내, 신고 버튼, 유사 상품 추천.

### 4.4 채팅
- 거래방(자동 생성) / 일반 1:1 문의 분리.
- 외부링크·전화번호·계좌번호 자동 마스킹(사기 예방).
- "거래 시작" 버튼 누르면 결제 페이지로 이동.

### 4.5 결제/거래방
- 결제 수단 선택 → 에스크로 보관 안내.
- 거래 진행 상태 머신:
  `결제대기 → 결제완료 → 인계대기 → 수령확인 → 정산예정 → 정산완료`
  분쟁 시: `→ 분쟁중 → 환불 / 정산`.

### 4.6 마이페이지
- 대시보드: 진행 거래 N건, 미정산 금액, 알림.
- 탭: 판매/구매/정산/평가/계정 보안.

### 4.7 관리자
- 분쟁 큐(우선순위/SLA 잔여 시간).
- 회원 검색/제재(메모, 영구정지, 한도조정).
- 통계: GMV, 거래 수, 분쟁율, 환불율, 신규가입.

## 6. 어뷰징/사기 예방 요건

- 채팅 내 외부 연락처 마스킹 + 외부거래 유도 시 신고 핫버튼.
- 동일 IP/디바이스/계좌의 자전거래 차단(신뢰 점수 페널티).
- 신규 계정 거래 한도제(가입 7일 미만, 일 한도 N만 원).
- 환불 사유별 통계로 어뷰저 자동 플래그(운영자 큐로 보냄).
