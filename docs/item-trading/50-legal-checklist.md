# 법무·보안·약관 체크리스트

> 본 문서는 **체크리스트**로, 실제 운영 전 반드시 변호사/세무사/PG·KISA 가이드 확인 필수.

---

## 1. 영업 형태 / 신고

- [ ] **통신판매업 신고** (관할 구청)
- [ ] **사업자등록** (업종: 전자상거래 / 통신판매중개)
- [ ] **부가통신사업 신고** 해당 여부 확인
- [ ] 자체 에스크로 운영 시 **전자금융업** 등록 또는 PG사의 에스크로 위임 구조 사용 검토
- [ ] **결제대행사 약정** (토스페이먼츠/이니시스/KG/카카오페이 등)
- [ ] **본인확인기관 위탁계약** (NICE/KCB/SCI)

---

## 2. 약관 / 정책 (필수 페이지)

- [ ] 이용약관
- [ ] 개인정보처리방침
- [ ] 위치정보 이용약관(필요 시)
- [ ] 환불/취소 정책
- [ ] 분쟁처리 정책 (`30-safety-escrow-dispute.md` 발췌)
- [ ] 게시물·아이템 등록 정책 (RMT 금지 게임, 불법 거래 금지)
- [ ] 청소년 보호정책 / 미성년자 거래 제한
- [ ] 권리침해 신고 절차(저작권·계정도용)
- [ ] 광고/마케팅 정보 수신 동의 (옵트인)

---

## 3. 개인정보 / 보안 (개인정보보호법 + 정보통신망법)

- [ ] 수집 최소화 원칙 (목적별 명시·동의)
- [ ] 주민번호 직접 수집 **금지** → 본인확인기관 CI/DI 사용
- [ ] 개인정보 처리시스템 접근통제(IP/계정/2FA)
- [ ] 접근 로그 1년 이상 보관
- [ ] **개인정보처리자 등록**, 개인정보보호 책임자 지정
- [ ] 비밀번호 단방향 해시(argon2/bcrypt), 길이/복잡도 정책
- [ ] 결제정보(PCI) — PG 위탁으로 토큰만 보관, 자체 저장 금지
- [ ] 정산계좌번호 등 민감정보 **암호화 저장(KMS)**
- [ ] 개인정보 파기 정책(탈퇴 후 30일 이내, 법정 보관 예외 명시)
- [ ] 위탁 처리 현황 공개(클라우드, PG, 본인확인사 등)
- [ ] 침해사고 대응 절차(KISA 신고 24/72시간 룰 숙지)

---

## 4. 게임사 약관 / RMT 이슈

- [ ] 카테고리에 등록할 각 게임의 **이용약관에서 RMT/현금거래 정책** 확인
- [ ] 명시적으로 금지된 게임은 **카테고리 자체 제외**
- [ ] 회색지대 게임은 위험 고지 노출 + 이용자 동의 게이트
- [ ] 게임사로부터 침해/시정요청 도착 시 처리 SOP

---

## 5. 자금세탁/이상거래

- [ ] 정산 출금 시 본인 명의 계좌 검증
- [ ] 1인 동일 IP/디바이스 다계정 탐지
- [ ] 단기간 대량 입출금 감지 룰
- [ ] 자금세탁방지(AML) 자문 — 거래액/패턴 보고 의무 검토

---

## 6. 미성년자 / 청소년

- [ ] 만 14세 미만 가입 제한 또는 법정대리인 동의
- [ ] 미성년자 결제 시 법정대리인 동의 절차 + 환불 청구 처리
- [ ] 청소년 유해 콘텐츠 등록 차단(상품명/이미지 검수)

---

## 7. 콘텐츠/저작권/광고

- [ ] 게임 스크린샷·BI 사용에 관한 페어유즈/라이선스 검토
- [ ] 사용자 업로드 이미지 저작권 신고/내림 절차
- [ ] 광고 노출 정책(상품 상위 노출 표시 — 공정거래법 표시 의무)

---

## 8. 보안 운영(OPSEC)

- [ ] 접근권한 최소화(역할 분리: ADMIN / CS / DEV)
- [ ] 운영자 행위 `AdminAuditLog` 필수 기록
- [ ] 시크릿/키 KMS 보관, .env 코드 저장 금지
- [ ] 의존성 취약점 정기 스캔(npm audit / Snyk)
- [ ] 정기 침투 테스트(연 1회 이상)
- [ ] 백업: DB 일일 + 7일 보관 + 월 단위 콜드 백업
- [ ] 결제·정산 시스템에 변경 시 **2인 승인** 정책

---

## 9. 출시 전 체크 리허설

- [ ] 결제/환불 e2e 시나리오 50건 통과
- [ ] 분쟁 SLA 시뮬레이션 (운영자 가이드북 v1)
- [ ] 약관/정책 페이지 모두 노출, 동의 시점 기록
- [ ] 장애 대응 매뉴얼 + 비상 연락망
- [ ] 이용자 신고 채널(이메일/전화/카톡) 가시성

---

## 10. 추가 자료/회의 메모 자리

- 일자/안건/담당
  - YYYY-MM-DD: 변호사 1차 자문 (전자금융업 등록 여부)
  - YYYY-MM-DD: PG사 미팅 (에스크로 위임)
  - YYYY-MM-DD: 본인확인기관 견적
