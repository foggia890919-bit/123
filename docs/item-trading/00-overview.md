## 1. 서비스 한 줄 요약

**"게임 내 재화(아이템·계정·캐릭터·골드·머니)를 안전하게 사고팔 수 있는 P2P 중개 거래 플랫폼."**

거래 당사자 간 신뢰 부족 문제를 **에스크로(안전거래)·고객센터 중재·게임사 연동 검수**로 해결한다.

---

## 2. 만드려는 이유 (Problem & Why now)

| 항목 | 내용 |
|---|---|
| 시장 문제 | 개인 직거래는 사기 위험이 크고, 카페/디스코드는 분쟁 시 보호 장치가 없다. |
| 기존 솔루션 한계 | 기성 사이트는 UI가 노후, 모바일 UX 빈약, 수수료 정책 불투명, 검색·필터링 약함. |
| 기회 | 모바일 게임 비중 확대로 거래 빈도가 늘었고, 간편결제·본인인증 인프라가 충분히 성숙. |
| 차별점 (가설) | ① 모바일 우선 UX  ② 거래 시세 자동 산정/추천  ③ 게임별 템플릿화된 등록 폼  ④ 자동 매칭 알림  ⑤ 분쟁 SLA 명시 |

## 3. 타깃 / 페르소나

### 3.1 판매자 (Seller)
- **A. 헤비 유저 / 부업형** — 골드·재화를 주기적으로 시세대로 처분.
  요구: 일괄 등록, 자동 가격 갱신, 정산 빠르게.
- **B. 은퇴/이탈 유저** — 계정/캐릭터 단건 매도.
  요구: 본인 인증·계정 안전 이관 보장.

### 3.2 구매자 (Buyer)
- **C. 신규/복귀 유저** — 시간 절약 위해 골드·아이템 구매.
  요구: 빠른 검색, 시세 신뢰, 결제 간편, 즉시 수령.
- **D. 컬렉터/하드코어** — 희귀 아이템 사냥.
  요구: 알림(워치리스트), 정밀 필터, 협상 채팅.

### 3.3 운영/CS
- **E. 운영자** — 분쟁 중재, 사기 모니터링, 정산 관리, 어뷰징 차단.

## 4. 거래 카테고리 (1차 출시 범위)

| 대분류 | 예시 | 비고 |
|---|---|---|
| 게임 머니/골드 | WoW 골드, 메이플 메소, 로아 골드 | 단위 거래량/시세 매칭 핵심 |
| 아이템 | 무기, 방어구, 강화재료, 펫 | 옵션/강화 수치 입력 필수 |
| 계정 | 캐릭터·계정 통째 양도 | 본인인증·비번 변경 가이드 강함 |
| 캐릭터 | 캐릭터 단건 양도 | 게임사 정책 확인 필요 |
| 기프트/쿠폰 | 기프트카드, 패키지 코드 | 코드 노출 방지 처리 |

> ⚠️ 게임사 약관상 RMT 금지 게임은 제외 또는 별도 카테고리로 분리. 법무 검토 필수 (`50-legal-checklist.md`).

## 5. 핵심 가치 제안 (Value Proposition)

- **안전**: 결제는 우리가 보관(에스크로). 수령 확인 후에만 정산.
- **빠름**: 자동매칭·간편결제·즉시 입금 알림.
- **편함**: 게임별 템플릿 + 검색 필터 + 시세 그래프.
- **공정**: 분쟁 시 SLA(예: 24시간 내 1차 답변), 양 당사자 진술·증빙 확보 후 결정.

## 6. 비즈니스 모델

| 수익원 | 설명 | 비율(가설) |
|---|---|---|
| 거래 수수료 | 판매자 또는 구매자 부담 | 거래액의 5~9% |
| 빠른 등록/상단 노출 | 유료 광고 슬롯, 키워드 광고 | 정액제 |
| 보험형 안심거래 추가 옵션 | 분쟁 시 우선 환불 보장 | 거래액의 +1% |
| 부가 서비스 | 시세 API, 대량등록 도구 | B2B |

비용: PG 수수료, 본인인증 비용, CS 인건비, 분쟁 환불 적립금.

## 7. 비기능 요구사항 (NFR)

- **가용성**: 99.9% 목표. 결제·정산 경로는 무중단 배포.
- **보안**:
  - 모든 통신 HTTPS, 비밀번호 bcrypt/argon2.
  - 결제·정산 로그 불변(append-only) 저장.
  - 채팅 메시지 보관 ≥ 1년 (분쟁 대응).
  - 개인정보 분리 저장(이름/주민번호 대체키), 접근 로그 남김.
- **성능**: 검색 결과 P95 < 500ms, 상품 등록 응답 < 1s.
- **모바일**: 1차부터 반응형 + PWA. 네이티브 앱은 2차.
- **국제화**: 1차 한국어, 추후 영어/중국어.

---

## 8. 1차 MVP 범위 (Out of Scope vs In Scope)

### In
- 회원가입/본인인증, 게임 1~2종 등록, 상품 등록·검색, 채팅, 에스크로 결제, 수동 분쟁처리, 정산.

### Out (2차 이후)
- 자동 시세 그래프, 모바일 네이티브 앱, 보험형 안심거래, 광고 시스템, 외화 결제.

---

## 9. 리스크 & 가정

- (R1) 게임사 약관 위반 이슈 → 카테고리 게이트키핑, 법률 자문.
- (R2) 사기 거래로 인한 환불/평판 손실 → 본인인증 강화, 한도제, 보험 적립.
- (R3) 결제대행사 정책 변경 → 다중 PG 연동.
- (R4) 어뷰징(자전거래/시세조작) → 디바이스 핑거프린트, 동일계좌 룰.
