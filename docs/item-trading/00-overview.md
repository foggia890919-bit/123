# 게임 아이템 거래 플랫폼 — 서비스 기획서 (PRD Overview)

> 벤치마크: 아이템매니아, 아이템베이 (그러나 1차 모델은 **게시판형**)
> 문서 버전: v0.2 (2026-04-26)
> 작성 위치: `docs/item-trading/`

---

## 1. 서비스 한 줄 요약

**"게임 아이템·머니·계정·상품권을 사고 팔 수 있는 게임별 팝니다/삽니다 게시판."**

- 1차 모델: **게시판형 중개 플랫폼**. 회사는 게시 공간과 검색·노출만 제공하고 **결제·거래는 회원 간 직접** 진행한다(외부거래 면책 고지).
- 수익 모델: **유료 상단노출(광고)** + **유료 끌올(자동 게시글 끌어올리기)** + 추후 옵션형 안전거래 수수료.
- 안전거래(에스크로)는 **2차 페이즈 옵션**으로 연결만 해두고, 1차에선 비활성화한다.

---

## 2. 만드려는 이유 (Problem & Why now)

| 항목 | 내용 |
|---|---|
| 시장 문제 | 카페·디스코드 거래는 검색·필터가 약하고 끌올·노출 정책이 임의적. 기성 사이트는 UI 노후, 모바일 UX 빈약. |
| 기회 | 게임 거래 수요는 전 연령에 걸쳐 꾸준하고, 게시판 + 광고 BM은 결제·정산·분쟁 부담 없이 빠르게 출시 가능. |
| 차별점 (가설) | ① 모바일 우선 UX  ② 게임별 템플릿화된 등록 폼 + 검색  ③ 정량화된 유료 상단노출 / 끌올 예약  ④ 분쟁 신고·자동 차단 자동화 |

---

## 3. 타깃 / 페르소나

> **타깃: 전 연령** (단 만 14세 미만은 법정대리인 동의 필요, 미성년자 결제는 회원이 직접 부담하는 구조라 광고 결제 시점에만 검증).

### 3.1 판매자 (Seller)
- **A. 헤비 유저 / 부업형 (벌크 셀러)** — 게임머니·재화를 자주 등록.
  요구: 일괄 등록, **자동 끌올 예약(유료)**, 상단노출 결제, 응답 시간 노출.
- **B. 일반 유저** — 안 쓰는 아이템·계정을 단건 매도.
  요구: 빠른 등록, 게임별 템플릿, 신고 보호.
- **C. 상품권 판매자** — 게임 상품권/문화상품권 등을 판매.
  요구: 코드 가림 처리, 사기 방지 안내.

### 3.2 구매자 (Buyer)
- **D. 신규/복귀 유저** — 시간 절약 위해 게임머니·아이템 구매.
  요구: 검색 필터, 판매자 신뢰도(평점/응답시간), 빠른 채팅.
- **E. 컬렉터/하드코어** — 희귀 아이템 사냥.
  요구: 워치리스트, 정밀 필터, 1:1 협상 채팅.

### 3.3 광고주(같은 사용자 풀) / 운영
- **F. 상단노출/끌올 결제자** — 판매자 본인이 광고비를 결제해 노출 강화.
- **G. 운영자** — 신고 처리, 분쟁 중재, 어뷰징 차단, 광고 결제 검증.

## 4. 거래 카테고리 (1차 출시 범위)

| 대분류 | 예시 | 등록 폼 핵심 필드 |
|---|---|---|
| 아이템 | 무기, 방어구, 강화재료, 펫 | 게임/서버/캐릭/옵션·강화수치/수량/이미지 |
| 게임머니 | 골드, 메소, 다이아 | 게임/서버/단위(1만 골드)/수량/단가/거래방법 |
| 계정 | 캐릭터·계정 통째 양도 | 게임/서버/레벨/주요 보유 아이템/스샷/이전 방법 |
| 상품권 | 문화상품권, 게임 충전권, 기프트카드 | 종류/액면가/수량/유효기간/코드 가림 안내 |

> 등록 폼 상세 정의는 `11-listing-form-schema.md`.
> ⚠️ RMT 금지 게임은 카테고리 자체에서 제외. 법무 체크리스트 51-1 항목 확인.

## 5. 핵심 가치 제안

- **빠른 등록/검색**: 게임별 템플릿 폼으로 옵션 표준화 → 검색이 정확.
- **공정한 노출**: 끌올 시점/상단노출 슬롯 가격이 **공개**되어 임의 노출 시비를 줄임.
- **자동 끌올(유료)**: 벌크 판매자가 시간 단위로 게시글을 자동 끌어올림.
- **외부거래 보호**: 회사가 결제에 개입하지 않아도, **채팅 마스킹·신고 자동화·평점**으로 사기 위험을 낮춤.

## 6. 비즈니스 모델

### 6.1 1차 (게시판 + 광고)

| 수익원 | 설명 | 가격 정책(가설) |
|---|---|---|
| **상단노출** | 카테고리/검색 결과 상단 N슬롯 노출 | 24h 1만/3만/5만 원 (슬롯·게임별 차등) |
| **자동 끌올** | 지정 시간 간격으로 게시글 자동 끌어올림 | 30분 간격 24h 5천 원 / 1시간 간격 24h 3천 원 / 패키지 |
| **메인 띠배너** | 메인 페이지 상단 띠 광고 | 일/주/월 단가 |
| **추천 키워드** | 게임/카테고리별 키워드 입찰 | CPC 또는 정액 |
| **벌크 셀러 멤버십** | 일괄 등록·끌올 무제한·통계 제공 | 월 19,900~99,000 원 |

### 6.2 2차 옵션 (안전거래/에스크로)

| 수익원 | 설명 |
|---|---|
| 안전거래 수수료 | 회사 결제 시스템(토스 에스크로) 사용 시 거래액의 5~9% |
| 보험형 안심거래 | 분쟁 시 우선 환불 보장 +1% |

비용: PG 수수료(광고 결제), 가상계좌 수수료, 본인인증 비용, CS 인건비, 인프라.

## 7. 비기능 요구사항 (NFR)

- **가용성**: 99.9% 목표. 광고 결제/끌올 스케줄러는 무중단.
- **보안**:
  - 모든 통신 HTTPS, 비밀번호 argon2/bcrypt.
  - 광고 결제 로그/끌올 실행 로그는 append-only 저장.
  - 채팅 메시지 보관 ≥ 1년(신고/분쟁 대응).
  - 개인정보 분리 저장, 접근 로그 1년 이상 보관.
- **성능**: 검색 결과 P95 < 500ms, 게시글 등록 응답 < 1s, 끌올 실행 지연 ≤ 30s.
- **모바일**: 1차부터 반응형 + PWA. 네이티브 앱은 2차.
- **국제화**: 1차 한국어, 추후 영어/중국어.

## 8. 1차 출시 범위 (게시판 + 광고/끌올)

> **MVP**라 부르지 않고 **"1차 정식 출시"** 로 본다. 이후 안전거래는 옵션 추가.

### 1차 In
- 회원가입(이메일/소셜) + 휴대폰 본인인증
- 게임 마스터(1~2종) + 카테고리 4종(아이템/게임머니/계정/상품권)
- 게임별 동적 등록 폼(템플릿) — `11-listing-form-schema.md`
- 게시글 등록/수정/삭제, 사진 업로드
- 검색·필터·정렬·페이지네이션
- **유료 상단노출** 결제(토스 카드/간편결제)
- **유료 자동 끌올 예약** 결제(토스 가상계좌 + 카드)
- 1:1 채팅(외부 연락처 마스킹) + 신고 버튼
- 평점·후기(거래 종료 셀프 표기)
- 신고/제재 어드민
- 알림(웹/이메일)
- 약관/개인정보/외부거래 면책 페이지

### 1차 Out (2차 이후)
- 안전거래(에스크로) 결제 — 2차 옵션
- 시세 그래프, 자동매칭, 모바일 네이티브 앱
- 다국어/외화 결제

## 9. 리스크 & 가정

- (R1) **게임사 약관 위반(RMT)** — 일부 게임은 현금거래 자체 금지 → 카테고리 게이트키핑 + 게임사 시정요구 SOP. (`51-legal-risks.md`)
- (R2) **외부거래 사기 발생 → 평판 하락** — 회사는 결제에 개입하지 않지만 신고/제재 빠르게. 안전거래 옵션 도입으로 단계적 해결.
- (R3) **광고 결제 환불/취소** — 끌올·노출은 시간 기반 → 이용 시작 후 부분 환불 정책 명시.
- (R4) **어뷰징(자전 등록·끌올 우회·도배)** — 동일 IP/디바이스/계좌 룰, 끌올 최소 간격 강제.
- (R5) **상품권 코드 사기** — 코드는 채팅에서 마스킹, 거래 전 노출 금지 안내.
- (R6) **미성년자 광고 결제** — 결제 페이지에서 본인인증 + 법정대리인 동의 모듈.
