# 텍스트 와이어프레임 — 상품 상세 / 거래방 / 분쟁

> Figma 산출물 전 단계의 **저충실도(low-fi) 텍스트 와이어**. 컴포넌트 위치·정보 우선순위·상태 변화에 집중.
> 모바일 우선 → 데스크탑은 동일 정보 + 좌우 2열 분할.

---

## 1. 상품 상세 (Listing Detail)

### 1.1 모바일 (≤ 768px)

```
┌──────────────────────────────────────┐
│ ← 뒤로   [공유] [신고] [♡찜]        │  ← 상단바 (고정)
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │       대표 이미지 (스와이프)     │  │  ← 1/N 인디케이터
│  │      [● ○ ○ ○]                  │  │
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│ [BADGE: 상단노출] [BADGE: 끌올중]     │  ← 광고 상태 배지
│ 게임 · 카테고리 · 서버                │
│                                      │
│  제목 (최대 2줄, 굵게)                │
│  ── 75,000 원 ──                     │
│  단위/수량: 1만 골드 × 50개          │
│  거래방법: 게임내전달                 │
│                                      │
│  옵션/상세 (카테고리별 동적 필드)     │
│   · 캐릭명: ___                      │
│   · 강화수치: +17                    │
│   · 옵션: 치명+12%, 쿨감-5%          │
├──────────────────────────────────────┤
│ ┌─ 판매자 카드 ───────────────────┐ │
│ │ [아바타]  닉네임   ⭐4.8 (132)   │ │
│ │ 평균 응답 12분 · 거래 320건      │ │
│ │ [판매자 게시글 보기 →]           │ │
│ └──────────────────────────────────┘ │
├──────────────────────────────────────┤
│ 상세 설명 (펼치기/접기)               │
│ 거래 정책 / 외부거래 면책 안내        │
│ 신고 사유: [부적절][사기의심][도용]   │
├──────────────────────────────────────┤
│ 비슷한 게시글 (가로 스크롤 카드)      │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│ [채팅하기]   [구매 요청]              │  ← 하단 sticky CTA
└──────────────────────────────────────┘
```

### 1.2 데스크탑 (≥ 1024px)
- 좌: 이미지 갤러리(고정 비율) + 상세 설명 + 비슷한 게시글
- 우(고정): 가격/CTA/판매자 카드 (스크롤 따라옴)

### 1.3 상태 변화
- `ACTIVE` → 위 그대로
- `PAUSED` → CTA 비활성 + "판매자가 일시중지" 배지
- `SOLD` → CTA "판매 완료" 비활성 + 비슷한 게시글 강조
- `BLOCKED` → 본문 흐림 + "운영 정책 위반으로 비공개" 안내

### 1.4 CTA 분기
- 비로그인: 클릭 시 로그인 모달 (소셜 우선) → 성공 시 의도 보존(원래 행동 자동 실행).
- 미인증(휴대폰): 채팅은 가능 / 구매요청은 인증 게이트.
- 본인 게시글: CTA 자리에 "끌올 결제 / 상단노출 결제" 노출.

## 2. 거래방 (Chat Room)

### 2.1 일반 거래 채팅

```
┌──────────────────────────────────────┐
│ ← 닉네임 (응답 12분) [신고] [차단]    │
├──────────────────────────────────────┤
│ ┌─ 거래 정보 카드 (고정) ─────────┐ │
│ │ [썸네일] 제목 · 75,000원        │ │
│ │ [상품 보기 →] [거래 시작 →]     │ │
│ └──────────────────────────────────┘ │
├──────────────────────────────────────┤
│ ─── 2026-04-25 ───                  │
│                                      │
│ [상대]  안녕하세요, 거래 가능?       │
│        12:01                        │
│                                      │
│ [나]    네, 어떤 서버이신가요?      │
│        12:03                        │
│                                      │
│ [상대]  ███-████-████ 로 보내주세요  │  ← ⚠️ 자동 마스킹
│        12:04   [⚠ 외부거래 신고]    │
│                                      │
│ ─── 시스템 ───                      │
│ 외부 연락처/계좌가 감지되어          │
│ 자동 가림 처리되었습니다.            │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│ [+] [메시지 입력......] [전송]        │
└──────────────────────────────────────┘
```

### 2.2 마스킹 규칙
- 휴대폰 / 카톡ID / 디스코드ID / 계좌번호 / URL → 검은 박스 처리.
- 마스킹 발생 시 시스템 메시지 자동 삽입 + "외부거래 신고" 인라인 버튼.

### 2.3 거래 시작 (안전거래 옵션 — 2차)

```
[거래 시작 →] 클릭
  → 모달
    "안전거래로 진행하시겠습니까?"
    수수료 5% / 정산 보류 시간 / 환불 조건
    [동의 후 결제] [취소]
  → 결제 페이지(/checkout/{orderId})
```

> 1차에는 안전거래 비활성. CTA를 **"구매 요청 (외부거래 안내)"** 로 표시.

### 2.4 거래 상태 머신 헤더 (안전거래 거래방 한정)

```
[● 결제대기]──[ 결제완료 ]──[ 인계대기 ]──[ 수령확인 ]──[ 정산완료 ]
                                              ↓
                                          [ 분쟁중 ]
```
- 현재 단계 강조, 클릭 시 단계 설명 툴팁.

## 3. 분쟁 (Dispute)

### 3.1 사용자: 분쟁 신청 폼

```
┌──────────────────────────────────────┐
│ 분쟁 신청                             │
├──────────────────────────────────────┤
│ 거래 정보 (자동) ─                    │
│  주문번호 / 거래일 / 금액 / 상대 닉   │
├──────────────────────────────────────┤
│ 사유 선택 (필수)                      │
│  ○ 인계가 안 됐어요                  │
│  ○ 옵션/수량이 다릅니다              │
│  ○ 사기 의심                         │
│  ○ 기타 (직접 입력)                  │
├──────────────────────────────────────┤
│ 상세 설명 (텍스트, 최소 30자)         │
│ ┌────────────────────────────────┐  │
│ │                                │  │
│ └────────────────────────────────┘  │
├──────────────────────────────────────┤
│ 증빙 첨부 (이미지/영상, 최대 8개)    │
│ [+ 추가]                             │
├──────────────────────────────────────┤
│ ☑ 사실과 다르게 신고 시 제재 동의     │
│                                      │
│ [취소]              [분쟁 접수하기]   │
└──────────────────────────────────────┘
```

### 3.2 사용자: 분쟁 진행 화면

```
┌──────────────────────────────────────┐
│ 분쟁 #D-2026-04250017                 │
│ 상태: 검토중   SLA 잔여: 21h 32m     │
├──────────────────────────────────────┤
│ 타임라인                              │
│  · 04-25 14:02  분쟁 접수            │
│  · 04-25 14:05  운영자 배정 (홍길동) │
│  · 04-25 14:30  증빙 추가 요청       │
│                  [증빙 추가하기 →]   │
│  · 진행중                            │
├──────────────────────────────────────┤
│ 상대방 진술 (운영자 검토 후 요약)     │
│  "인계 우편 14:00 발송, 스샷 첨부"   │
├──────────────────────────────────────┤
│ 운영자 메시지                         │
│  "양측 증빙 받는 대로 24시간 내      │
│   1차 결정 드립니다."                │
├──────────────────────────────────────┤
│ [추가 증빙 첨부] [채팅 원문 요청]     │
└──────────────────────────────────────┘
```

### 3.3 운영자(어드민): 분쟁 처리 화면

```
┌─ 좌: 큐 ──────────┬─ 우: 디테일 ──────────────────┐
│ 우선순위 / SLA   │ 분쟁 #D-...                    │
│ ▣ 12h 남음  HOT  │ 거래 / 결제 / 채팅 원문(원본)  │
│ □ 24h 남음       │ 양측 진술 요약 + 증빙 갤러리   │
│ □ 36h 남음       │                                │
│                   │ ─ 결정 ─                       │
│                   │ ○ 환불 (전액)                  │
│                   │ ○ 정산 진행                    │
│                   │ ○ 부분 환불 [_] %             │
│                   │ 사유/메모 [______________]     │
│                   │ 첨부할 운영자 로그 자동 기록   │
│                   │                                │
│                   │ [임시 저장] [결정 발행]        │
└───────────────────┴────────────────────────────────┘
```

- 모든 결정은 `AdminAuditLog`에 actor/diff/reason 기록.
- 결정 발행 시 양측에 알림(앱/이메일) + 결제·정산 자동 집행.

### 3.4 알림 카피 (예시)

- 신청 직후: "분쟁이 접수되었습니다. 1차 답변까지 최대 24시간 소요됩니다."
- 결정 환불: "분쟁 #D-... 결과: 전액 환불. 결제 수단으로 영업일 N일 내 환급."
- 결정 정산: "분쟁 #D-... 결과: 거래 완료. 정산이 진행됩니다."
