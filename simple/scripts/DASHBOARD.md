# Looker Studio 대시보드 셋업 (5분, 무료)

Google Sheet 데이터를 시각화. 매출 추이 / 키워드별 비교 / 시장 점유율 등.

## 1. Looker Studio 접속

https://lookerstudio.google.com → 본인 구글계정 (시트 소유자) 로그인

## 2. 데이터 소스 연결

1. 좌상단 「+ 만들기」 → 「데이터 소스」
2. 「Google Sheets」 선택
3. 매출보고 시트 선택
4. **「주문원본」 탭** 선택 → 「연결」
5. 칼럼 인식 확인 (필요 시 데이터 유형 조정 — 결제일 = 날짜, 매출/이익 = 숫자)

같은 방식으로 「일일집계」, 「시장조사_시장규모」, 「순위추적_데이터」도 추가 데이터 소스로 연결.

## 3. 보고서 만들기

좌상단 「+ 만들기」 → 「보고서」 → 위 데이터 소스 선택

### 추천 차트

#### A. 일별 매출 추이 (시계열 차트)
- 차트 → 시계열 차트
- 데이터: 「주문원본」
- 측정기준 (X축): 결제일
- 측정항목 (Y축): 매출 (합계)
- 분류 (Color): 스토어
- 필터: 상태 ≠ 취소

#### B. 키워드별 매출 (가로 막대)
- 차트 → 막대 차트 (가로)
- 측정기준: 키워드
- 측정항목: 매출 (합계), 이익 (합계)
- 정렬: 매출 ↓
- 필터: 상태 ≠ 취소

#### C. 스토어 비교 (도넛)
- 차트 → 원형 차트
- 측정기준: 스토어
- 측정항목: 매출 (합계)

#### D. 일별 이익률 (선 차트)
- 측정기준: 결제일
- 측정항목: 이익률 = SUM(이익) / SUM(매출) × 100
- (계산된 필드: 데이터 소스에서 「+ 필드 추가」)

#### E. 시장 점유율 (계산 필요)
1. 「주문원본」 일별 매출 합계
2. 「시장조사_시장규모」 일별 시장규모
3. 점유율 = 우리 매출 / 시장 매출
4. 새 차트: 일별 점유율 추이

#### F. 순위 추적
- 데이터: 「순위추적_데이터」
- 측정기준: 수집일
- 측정항목: 순위 (평균)
- 분류: 키워드 또는 라벨

### 페이지 분리 (선택)

- 1페이지: 매출 요약 (오늘/이번주/이번달)
- 2페이지: 스토어별 상세
- 3페이지: 키워드/카테고리 분석
- 4페이지: 시장조사 + 점유율
- 5페이지: 순위추적

## 4. 자동 새로고침

- 보고서 → 「파일」 → 「보고서 설정」 → 「데이터 새로고침: 15분 간격」
- 매일 8시 cron 이 시트 갱신 → Looker 자동 반영

## 5. 모바일 접근

- 보고서 우상단 「공유」 → 「링크 가져오기」 → 본인 휴대폰에 북마크
- Looker Studio 모바일 웹 자동 반응형
- Android/iOS 앱은 없지만 모바일 브라우저로 충분

## 6. 한 번에 여러 사람 (옵션)

- 「공유」 → 이메일 추가 → 「뷰어」 권한
- 매니저/직원에게 공유 가능
- 단, 시트 데이터 접근 권한도 따로 부여 필요

---

## 빠른 시작 — 최소 차트 3개

처음에는 이거 3개만:
1. **일별 매출 추이** (시계열 / 매출 + 이익 두 줄)
2. **키워드별 매출** (가로 막대 / 상위 10)
3. **스토어 비교** (도넛)

→ 5분이면 만들고, 추가 차트는 천천히.

## 트러블슈팅

| 증상 | 해결 |
|---|---|
| 시트 연결 시 권한 오류 | 시트 소유자 구글계정으로 로그인 / Service Account 아닌 본인 계정 |
| 칼럼이 텍스트로만 인식 | 데이터 소스 편집 → 해당 칼럼 「유형」 변경 (날짜/숫자) |
| 차트 비어있음 | 필터 확인 / 날짜 범위 너무 좁음 / 측정기준 비어있는지 |
| 「취소」 행이 합계에 들어감 | 차트 필터 「상태 ≠ 취소」 추가 |
| 데이터 갱신 안 됨 | 보고서 새로고침 (Ctrl+R) 또는 「파일 → 새로고침」 |
