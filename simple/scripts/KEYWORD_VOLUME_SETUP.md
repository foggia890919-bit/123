# 「키워드 검색량 조회」 시트 셋업 (5분, 무코딩)

Google Sheet 안에서 키워드 입력 → 메뉴 클릭 → 검색량 자동 채워짐.

## 1. Apps Script 열기

1. 「매출보고」 시트 열기
2. 메뉴 「**확장 프로그램**」 → 「**Apps Script**」 클릭
3. 새 탭에서 스크립트 편집기 열림

## 2. 코드 붙여넣기

1. 편집기에 기본 `function myFunction() {}` 같은 코드 있으면 **전부 삭제**
2. `simple/scripts/keyword_volume.gs` 파일 내용 **전체 복사** (사장님 노트북에서 GitHub 또는 Lightsail 에서 보고 복사)
3. 편집기에 붙여넣기
4. 좌상단 「**저장**」 (디스크 아이콘) 또는 Ctrl+S
5. 프로젝트 이름 묻는 창 → 「**키워드도구**」 입력 → 확인

## 3. API 키 등록 (스크립트 속성)

1. 좌측 메뉴의 **⚙️ 「프로젝트 설정」** 클릭
2. 아래로 스크롤 → **「스크립트 속성」** 섹션
3. 「**스크립트 속성 추가**」 클릭 → 3개 등록:

| 속성 | 값 |
|---|---|
| `NAVER_AD_API_KEY` | (검색광고 API 라이선스 — `01000000...` 으로 시작하는 긴 문자열) |
| `NAVER_AD_SECRET` | (비밀키 — `AQAAAAB...` 으로 시작) |
| `NAVER_AD_CUSTOMER_ID` | `3716495` (또는 사장님 고객 번호) |

→ 「**스크립트 속성 저장**」 클릭

## 4. 시트로 돌아가서 새로고침

1. 시트 탭으로 이동 (또는 시트 URL 다시 열기)
2. **F5** 새로고침
3. 메뉴 막대에 **「🔍 키워드 도구」** 새 메뉴 나타남

## 5. 첫 실행 — 권한 승인

1. 「🔍 키워드 도구」 → 「**탭 초기화**」 클릭
2. 첫 실행이라 권한 승인 팝업:
   - 「검토」 → 본인 계정 선택 → 「고급」 → 「**키워드도구(안전하지 않음)** 으로 이동」 → 「허용」
3. 「키워드검색량」 탭 자동 생성

## 6. 사용

1. 「키워드검색량」 탭 → **A4 부터 키워드 한 줄에 하나씩 입력**:
   ```
   A4: 올리브오일
   A5: 엑스트라버진
   A6: 피쿠알
   A7: 끌로에 가방
   ...
   ```
2. 메뉴 「🔍 키워드 도구」 → 「**검색량 조회 (선택 키워드)**」 클릭
3. 우상단에 「N개 키워드 조회 중…」 토스트 나타남
4. 잠시 후 B~F 칼럼에 자동 채워짐:
   - B: PC 월검색
   - C: 모바일 월검색
   - D: 합계
   - E: 경쟁도 (낮음/중간/높음)
   - F: 수집일

100개 키워드면 약 30~60초 소요.

## 7. 「버튼」 만들기 (선택)

원하시면 시트에 진짜 버튼:
1. 메뉴 「**삽입**」 → 「**그리기**」
2. 「텍스트 상자」로 「▶ 검색량 조회」 그리기 → 「저장 후 닫기」
3. 시트에 그림 나타남
4. 그림 우클릭 (또는 ⋮ 점 3개) → 「**스크립트 할당**」
5. 함수 이름 입력: `fetchKeywordVolumes`
6. 확인

이제 그림 클릭만 하면 실행. 메뉴 안 거쳐도 됨.

## 트러블슈팅

| 증상 | 해결 |
|---|---|
| 메뉴 「🔍 키워드 도구」 안 보임 | F5 새로고침. 안 되면 Apps Script 편집기에서 `onOpen` 함수 한 번 직접 실행. |
| 「API 미설정」 오류 | 프로젝트 설정 → 스크립트 속성에 3개 다 들어갔나 확인 |
| 「API 401/403」 오류 | API 키 값 정확한지 확인. Customer ID 가 숫자 (따옴표 X) 인지. |
| 「실행 시간 초과 (6분)」 | 키워드 너무 많음. 100개 이내로 나눠서 실행 |
| 검색량 0 | 「< 10 」 또는 미등록 키워드. 정상 (검색량 매우 적음) |

## 일별 자동 갱신 (선택)

매일 자동으로 검색량 갱신하고 싶으면:
1. Apps Script 편집기 → ⏰ 「트리거」
2. 「+ 트리거 추가」
3. 함수: `fetchKeywordVolumes`
4. 시간 기반: 매일 09시
5. 저장

→ 매일 9시에 자동으로 모든 키워드 검색량 새로고침.
